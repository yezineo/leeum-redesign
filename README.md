# 리움미술관 웹사이트 리디자인

> 리움미술관 웹사이트를 분석해, 전시를 보고 예약하고 방문을 준비하기까지의 관람 경험을 개선한 UX/UI 리디자인 프로젝트입니다.
> 회원가입·로그인·전시 예약을 실제로 동작하도록 구현했고, 덜 붐비는 시간을 고를 수 있는 AI 혼잡도 예측과 관람 안내 챗봇을 추가했습니다.

※ 본 프로젝트는 실제 서비스를 기반으로 제작한 UX/UI 리디자인 학습 목적의 비공식 컨셉 작업이며, 리움미술관과 무관합니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 회원가입 · 로그인 | 비밀번호 bcrypt 암호화 저장, 이메일 중복 확인, 이메일 저장(쿠키), 로그인이 필요한 화면은 로그인 후 원래 가려던 곳으로 복귀 |
| 전시 예약 | 실제 오늘 날짜 기준 달력(14일 전부터 예약, 매주 월요일 휴관, 전시 종료 후 예약 불가) → 시간·인원 선택 → 확인 → 저장 |
| AI 예상 혼잡도 | 머신러닝 모델이 날짜·시간별 혼잡도(여유/보통/혼잡)를 예측해 예약 시간 버튼에 표시 |
| 예약 내역 · 마이페이지 | 다가오는 예약 / 지난 예약 구분, 본인 예약만 조회 가능, 메인에 가장 가까운 예약 표시 |
| 전시 목록 · 상세 | 현재/예정/과거 탭, 상세 템플릿 1개로 전시 14개 표시, 기간이 지나면 자동으로 "종료된 전시" 표시 |
| AI 챗봇 | 자주 묻는 질문은 즉시 답변, 직접 입력은 OpenAI가 확인된 미술관 정보 안에서만 답변, 대화 여러 개 보관 |

## 기술 스택

- **Backend**: Python 3.12, Flask, Jinja2
- **Database**: MySQL (PyMySQL)
- **Frontend**: HTML, CSS(디자인 토큰 기반), JavaScript (프레임워크 없이)
- **AI**: OpenAI API (`gpt-4o-mini`) 챗봇, scikit-learn RandomForest 혼잡도 예측
- **Design**: Figma
- **배포**: Render (웹 서버), Aiven (MySQL)

## AI 기능 설명

### 1. 혼잡도 예측 (머신러닝)
- **왜**: 원본 사이트의 "쾌적한 관람을 위해 예약해 주세요" 안내는 있지만, 사용자가 덜 붐비는 시간을 고를 정보는 없었습니다.
- **데이터**: 실제 방문 데이터는 공개되지 않아, 요일·시간·계절 패턴을 반영한 **가상 데이터**(2024.01~2026.09)를 만들어 학습했습니다. 실제 데이터로 교체할 수 있는 구조입니다.
- **모델**: RandomForest (특성: 요일, 시간, 월, 주말 여부)
- **평가** (마지막 6개월을 시험용으로 분리)

| | 평균 오차(MAE) | R² |
|---|---|---|
| 단순 평균 (요일·시간별) | 13.8명 | 0.770 |
| **RandomForest** | **12.2명** | **0.815** |

- **표시**: 예측 인원 하위 40% = 여유, 상위 25% = 혼잡. 색만으로 구분하지 않고 글자로 함께 표시했습니다.

### 2. AI 챗봇
- 빠른 질문(관람 시간, 위치 등)은 미리 준비한 답을 바로 보여주고, 직접 입력한 질문만 AI에 보냅니다.
- AI에는 확인된 미술관 정보만 제공하고, 모르는 내용은 지어내지 않고 대표전화로 안내하도록 했습니다.
- API 키가 없거나 오류가 나면 안내 문구로 대신합니다.

## 실행 방법

### 1. 설치
```bash
git clone https://github.com/yezineo/leeum-redesign.git
cd leeum-redesign
pip install -r requirements.txt
```

### 2. 데이터베이스
MySQL Workbench에서 `db/schema.sql`을 실행합니다.
DB, 테이블, 앱 전용 계정(`leeum`)이 만들어집니다. **비밀번호는 원하는 값으로 바꿔서 사용하세요.**

### 3. 환경 변수
`.env.example`을 복사해 `.env` 파일을 만들고 값을 채웁니다.
```
DB_HOST=localhost
DB_PORT=3306
DB_USER=leeum
DB_PASSWORD=schema.sql에서 정한 비밀번호
DB_NAME=leeum
DB_SSL_CA=비워두기 (외부 DB에 SSL로 연결할 때만 인증서 파일 이름)
SECRET_KEY=아무 긴 문자열
OPENAI_API_KEY=본인 OpenAI 키 (없으면 챗봇은 빠른 질문만 동작)
```

## 폴더 구조

```
app.py               라우트 (메인 · 전시 · 예약 · 로그인 · 챗봇)
exhibitions_data.py  전시 데이터 (상세 템플릿 1개가 이 데이터로 화면 생성)
db.py                MySQL 연결
ca.pem               배포용 외부 DB(Aiven) SSL 인증서
chat_ai.py           OpenAI 챗봇
crowd.py             혼잡도 예측 불러오기
ml/                  가상 데이터 생성 · 모델 학습 · 학습된 모델
db/schema.sql        DB · 테이블 생성 SQL
templates/           화면 (Jinja2)
static/              CSS · JS · 이미지
```

## 범위 밖 (확장 가능)

- 예약 취소, 잔여 좌석, 결제, 관리자 화면
- 비밀번호 찾기 · 재설정은 화면만 구현
- 예약은 현재 전시 1개만 지원 — 전시 데이터 구조라 여러 전시로 확장 가능
